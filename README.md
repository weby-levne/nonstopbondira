# NONSTOP BONDIRA – web

Minimalistický responzivní web pro mobilní pneuservis a autoservis.

## Struktura

```text
bondira-web/
├── index.html
├── styles.css
├── script.js
├── README.md
└── assets/
    ├── hero.jpg
    └── van.jpg
```

## GitHub Pages

1. Vytvoř nový GitHub repository.
2. Nahraj všechny soubory z této složky.
3. V repository otevři **Settings → Pages**.
4. Jako Source vyber **Deploy from a branch**.
5. Vyber `main` a `/ (root)`.
6. Ulož. GitHub ti zobrazí adresu webu.

## Důležité před zveřejněním

- Ověř všechny kontaktní údaje.
- Nahraď ukázkové/fotografické materiály vlastními fotografiemi, pokud máš oprávnění je používat.
- Kontaktní formulář je čistě statický a otevírá e-mailového klienta přes `mailto:`. Pro skutečné odesílání bez e-mailového programu je potřeba backend nebo formulářová služba.
- Pokud web zveřejňuješ pro skutečnou firmu, doplň podle potřeby IČO, obchodní údaje, zásady ochrany osobních údajů a další právně potřebné informace.
